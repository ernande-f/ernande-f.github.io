## 📖 Sobre o Projeto

Este é o portfólio oficial de **Ernande**, um editor de vídeos focado em produzir conteúdo dinâmico (Reels, TikToks, Shorts) e vídeos institucionais. O site foi projetado com uma estética premium e minimalista (Cinema Noir), utilizando animações fluídas para refletir a alta qualidade do trabalho audiovisual entregue aos clientes.

## ✨ Features e Destaques

*   **Design Premium**: Paleta de cores escura com alto contraste (vermelho/verde) que evoca o universo cinematográfico.
*   **Animações GSAP**: Rolagem suave (ScrollTrigger) e elementos interativos que reagem ao usuário, criando uma experiência imersiva.
*   **Acessibilidade e Performance**:
    *   Suporte a navegação por teclado (foco visível).
    *   Prevenção nativa contra Layout Shifts (CLS) em todas as imagens.
    *   Integração com a preferência de sistema para *Reduced Motion* (`prefers-reduced-motion`).
*   **SEO Otimizado**: Estrutura semântica, meta tags nativas do Open Graph e estruturação JSON-LD Schema (ProfilePage/Person) para destaque nos motores de busca (Google).
*   **Galeria Interativa**: Visualização dos vídeos de portfólio diretamente pelo navegador usando um modal leve e responsivo consumindo o player nativo otimizado do YouTube.
